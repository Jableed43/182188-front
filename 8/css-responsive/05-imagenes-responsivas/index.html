Imágenes Responsivas Inteligentes

Las imágenes de abajo nunca se salen de su contenedor ni se deforman.

Sin la regla de rescate ❌

Esta imagen NO tiene max-width: 100%. Achicá la ventana y va a desbordar.

Con la regla de rescate ✅

img {
  max-width: 100%;
  height: auto;
  object-fit: cover;
}

Galería con object-fit: cover

Todas las cajas miden 200x200 sin importar la proporción original de la foto.
