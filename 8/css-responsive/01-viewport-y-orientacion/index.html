¿Qué hace el viewport?

width=device-width le dice al navegador que use el ancho real del dispositivo, no un ancho falso de escritorio. initial-scale=1.0 evita el zoom automático.

Prueba: comentá la etiqueta <meta name="viewport"> en el HTML y recargá. Vas a ver todo minúsculo.
