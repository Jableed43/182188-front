Dos formas de escribir la misma regla

Achicá y agrandá la ventana. Las dos tarjetas cambian igual, solo cambia cómo se escribió el CSS.

Sintaxis Tradicional

@media screen and (min-width: 768px) { ... }
@media screen and (max-width: 767px) { ... }

/* Rango con dos condiciones unidas por "and" */
@media screen and (min-width: 768px) and (max-width: 1200px) {
  .contenedor { padding: 20px; }
}
Cambio con min-width

Sintaxis Moderna (operadores)

@media (width >= 768px) { ... }   /* = min-width: 768px */
@media (width <= 767px) { ... }  /* = max-width: 767px */

/* Rango en una sola línea */
@media (768px <= width <= 1200px) {
  .contenedor { padding: 20px; }
}
Cambio con width >=

Rango específico: entre 768px y 1200px

Este contenedor solo tiene relleno extra cuando el ancho está EXACTAMENTE entre 768px y 1200px. Fuera de ese rango, vuelve a su padding normal.

Rango 768px – 1200px

⚠️ Compatibilidad

La sintaxis moderna (width >=) es más legible pero requiere navegadores actualizados (Chrome/Edge 104+, Firefox 63+, Safari 16.4+). Para proyectos que deben soportar navegadores viejos, usá la sintaxis tradicional con min-width / max-width.
