# Clase 08 · Responsive Design y Unidades Relativas

Material de práctica para la clase. Cada carpeta es un ejemplo HTML + CSS autocontenido: se abre el `index.html` en el navegador y se prueba achicando/agrandando la ventana (o con el simulador de celulares de Chrome, `Ctrl + Shift + M`).

## Orden sugerido

1. **`01-viewport-y-orientacion`** — La etiqueta `<meta name="viewport">` y la media query `orientation` (portrait vs landscape).
2. **`02-mobile-first-breakpoints`** — Filosofía Mobile-First con `min-width` en 768px y 1024px, más la tabla de breakpoints estándar de la industria (576 / 768 / 992 / 1200px).
3. **`03-sintaxis-tradicional-y-moderna`** — Comparación entre `min-width`/`max-width` y la sintaxis moderna con operadores (`width >=`, rango `768px <= width <= 1200px`).
4. **`04-unidades-fluidas-clamp`** — Unidades relativas (`%`, `vw`, `vh`) y tipografía fluida con `clamp()`.
5. **`05-imagenes-responsivas`** — La regla de oro (`max-width: 100%`, `height: auto`) y `object-fit: cover` en una galería.
6. **`06-modo-oscuro`** — Media query de sistema operativo `prefers-color-scheme: dark`.
7. **`07-ejercicio-practico`** — Ejercicio de clase resuelto: grilla de 3 productos con Flexbox, Mobile-First, con la consigna completa y pistas sobre `flex-wrap` y `justify-content`.
