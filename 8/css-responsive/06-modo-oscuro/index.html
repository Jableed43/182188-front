Media Queries del Sistema Operativo

Este sitio lee la preferencia de tema de tu Windows/celular. Probá cambiarla en la configuración del sistema.

¿Cómo funciona?

La media query prefers-color-scheme no depende del ancho de pantalla, sino de una preferencia que vive en el sistema operativo del usuario.

Modo actual

☀️ Estás en modo claro 🌙 Estás en modo oscuro

¿Dónde lo cambio?

Windows: Configuración → Personalización → Colores → Elegir modo.

Chrome DevTools: Ctrl+Shift+P → escribí "rendering" → "Emulate CSS prefers-color-scheme".
