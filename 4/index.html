Clase 04 — HTML Semántico, Formularios y Multimedia

Módulo 1: Arquitectura y Maquetación Moderna · Unidad 04

¿Qué vamos a aprender?

En esta clase dejamos de "dibujar cajas" con <div> y empezamos a escribir HTML con significado. Vas a poder:

  • Estructurar una página con etiquetas semánticas (<header>, <main>, <article>, <aside>…).
  • Construir formularios y dominar los tipos de <input>.
  • Insertar imágenes, audio, video e iframes.
  • Entender la accesibilidad básica (ARIA) y por qué importa.

Recorrido de ejemplos (en orden)

  1. 1. HTML Semántico — el layout con header, main, section, article, aside y footer.
  2. 2. Accesibilidad (ARIA) — role, aria-label y tabindex.
  3. 3. Formularios — el universo <input>, label, select, textarea y GET vs POST.
  4. 4. Multimedia — img, audio, video e iframes.
  5. 5. display:none vs visibility:hidden — cómo ocultar elementos (adelanto de CSS).
  6. 6. Desafío de clase — armá tu propio formulario de registro (con solución comentada).
✅ Consejo: no te limites a mirar la página renderizada. Abrí el código de cada archivo (en VS Code o con Ctrl+U en el navegador) y leé los comentarios: ahí está explicado cada concepto paso a paso.
