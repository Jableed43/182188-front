# Clase 04 — HTML Semántico + Formularios + Multimedia

Curso Front-End · Módulo 1: Arquitectura y Maquetación Moderna · **Unidad 04**

Esta carpeta contiene ejemplos **para revisar y practicar**. Cada archivo está
lleno de comentarios que explican el *qué* y, sobre todo, el *por qué* de cada
etiqueta.

## 🎯 Objetivos de la clase

- Implementar etiquetas semánticas (`<header>`, `<main>`, `<aside>`, `<article>`…) correctamente.
- Dominar los tipos de `<input>` (email, date, color, radio, checkbox…) y sus validaciones.
- Insertar contenido multimedia: imágenes, audio, video e iframes.
- Comprender la accesibilidad web básica (atributos ARIA y `alt`).

## ▶️ Cómo usar esta carpeta

1. Abrí la carpeta `4` en **Visual Studio Code**.
2. Clic derecho sobre `index.html` → **Open with Live Server**.
3. Recorré los ejemplos en orden desde el índice.
4. **Leé el código fuente** de cada archivo (en VS Code o con `Ctrl+U` en el
   navegador): la explicación de cada concepto está en los comentarios.
